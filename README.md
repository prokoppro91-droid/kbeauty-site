# K-Beauty Profi — сайт-каталог (варіант 1)

Каталог **корейської професійної косметики та косметології** з поділом на категорії.
Стиль бренду K-Beauty Profi 🇰🇷 (золото + пастель).

## Як відкрити
Подвійний клік на `index.html`. Працює локально, без сервера.

## Що всередині
- Два розділи каталогу:
  - 🧴 **Косметика для догляду** — креми, сироватки, очищення, тонери, маски, сонцезахист, догляд за очима;
  - 💉 **Професійна косметологія** — мезотерапія, біоревіталізація, філери, ботулотоксин,
    колагеностимулятори, нитки, пілінги, апаратні розхідники.
- Категорії-плитки з лічильником товарів, фільтри-чіпи, пошук, сортування.
- Картка товару з модальним вікном (опис, теги, фасування, ціна).
- Кошик (зберігається у браузері) + оформлення замовлення через Instagram.
- Адаптив під телефон/планшет.

## Файли
- `index.html` — сторінка
- `styles.css` — стилі
- `products.js` — **дані товарів і категорій** (редагуйте тут)
- `app.js` — логіка каталогу

## Як додати/змінити товар
У `products.js` додайте об'єкт у масив `PRODUCTS`:
```js
{ id:200, name:"Назва", brand:"Бренд", group:"care", cat:"cream",
  vol:"50 мл", price:500, old:600, badge:"new",
  desc:"Опис.", tags:["тег1","тег2"] }
```
- `group`: `"care"` (косметика) або `"pro"` (косметологія)
- `cat`: id категорії з масиву `CATEGORIES`
- `badge` (необов'язково): `"hit"` | `"new"` | `"pro"`
- для професійних додайте `pro:true` (мітка «лише для фахівців»)

## Примітка
Зображення товарів — стильні емодзі-плейсхолдери (працюють всюди, без файлів).
За потреби можна замінити на реальні фото — додавши поле `img` у товар і
відрендеривши `<img>` замість емодзі в `app.js`.

Ін'єкційні препарати показані як професійні засоби з відповідним застереженням —
відпуск лише сертифікованим фахівцям, ціни орієнтовні.
